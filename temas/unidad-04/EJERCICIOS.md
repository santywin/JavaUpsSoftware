# Ejercicios · Unidad 4

Crea tus soluciones en `curso.unidad04.practica`. En IntelliJ usa New → Package y New → Java Class. Cada clase ejecutable necesita main. Para los ejercicios conceptuales, basta una explicación, pseudocódigo o diagrama.

## 1. Promedio

Calcula el promedio de un arreglo no vacío.

**Para comprobar:** {8, 6, 10} → 8.0.

## 2. Búsqueda

Indica si un valor aparece en un arreglo.

**Para comprobar:** En {2, 4, 6}, 4 existe y 5 no.

## 3. Máximo

Busca el mayor sin ordenar.

**Para comprobar:** {-8, -3, -12} → -3.

## 4. Matriz

Suma cada fila y luego cada columna.

**Para comprobar:** {{8, 6}, {10, 7}} → filas 14 y 17; columnas 18 y 13.

## 5. Burbuja

Ordena de menor a mayor intercambiando vecinos.

**Para comprobar:** {5, -2, 5, 1} → {-2, 1, 5, 5}; también prueba arreglo vacío.

## 6. Selección

Ordena buscando el mínimo pendiente.

**Para comprobar:** Prueba vacío, un valor, repetidos y datos ya ordenados.

## 7. Texto

Compara dos textos sin distinguir mayúsculas y cuenta su longitud.

**Para comprobar:** Java y java coinciden sin distinguir mayúsculas; Java tiene longitud 4.

## 8. Vocales

Cuenta a, e, i, o y u sin tildes, admitiendo mayúsculas.

**Para comprobar:** Java → 2; JAVA → 2; texto vacío → 0.

Entrega el código y una tabla con entrada, resultado esperado y resultado obtenido. En los primeros ejemplos numéricos se supone una entrada del tipo indicado; la validación de texto es una ampliación posterior.

## 9. Primera coincidencia

Devuelve la posición de la primera coincidencia o -1.

**Para comprobar:** {8,4,9,4}, buscar 4 → 1; buscar 7 → -1; vacío → -1.

## 10. Invertir

Invierte el mismo arreglo intercambiando sus extremos.

**Para comprobar:** {1,2,3,4} → {4,3,2,1}; prueba vacío y un solo elemento.

## 11. Orden descendente

Adapta burbuja para ordenar de mayor a menor.

**Para comprobar:** {5,-2,5,1} → {5,5,1,-2}.

## 12. Resumen por columna

Calcula el promedio de cada columna de una matriz rectangular no vacía.

**Para comprobar:** {{8,6},{10,7}} → 9.0 y 6.5.
