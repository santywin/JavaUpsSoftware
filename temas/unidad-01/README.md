# Unidad 1. Introducción al lenguaje de programación

## 1.1 Los sistemas informáticos

Hardware es la parte física y software son los programas. La entrada recibe datos, el procesador realiza operaciones, la memoria conserva los datos en uso y la salida muestra resultados.

## 1.2 Lenguajes y paradigmas de programación

Un lenguaje define cómo escribir instrucciones. Un paradigma es una manera de organizar una solución: imperativo (pasos y cambios de estado), orientado a objetos (datos y comportamiento reunidos) o funcional (composición de funciones). Un lenguaje puede admitir varios. Java permite escribir soluciones imperativas y orientadas a objetos; no necesitas dominar objetos para empezar.

## 1.3 Diseño de algoritmos

Antes de escribir Java identifica datos de entrada, pasos y resultado. Escribe pseudocódigo y prueba a mano con números pequeños. En un diagrama de flujo, el óvalo representa inicio/fin; el paralelogramo, entrada/salida; el rectángulo, proceso; y el rombo, decisión. Las flechas indican el recorrido.

## 1.4 Bases del lenguaje de programación

Ejecuta primero un mensaje. Después modifica texto y lee el teclado. La sintaxis son las reglas de escritura; la semántica es el significado de las instrucciones. Por ejemplo, olvidar un punto y coma puede impedir compilar; multiplicar cuando querías sumar puede compilar y aun resolver mal el problema. Aquí solo usamos variables sencillas; los tipos se estudian en la unidad 2.
