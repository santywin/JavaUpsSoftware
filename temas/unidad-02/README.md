# Unidad 2. Tipos de datos y estructuras de control

## 2.1 Tipos de datos y conversiones

Empieza con String para texto, int para enteros y double para decimales. Añade boolean al estudiar decisiones y char al trabajar caracteres. Una conversión de double a int descarta la fracción; no redondea. No todos los valores caben en todos los tipos. Usa ejemplos pequeños y prueba los límites del problema.

## 2.2 Operadores y expresiones

Practica +, -, * antes de / y %. Compara división entera y decimal. Los paréntesis agrupan cálculos. Más adelante, ++ incrementa en uno y += acumula; escribe primero sus formas completas para entenderlos.

## 2.3 Sentencias de selección

if decide según una condición. Una cadena if/else if/else elige un camino; varios if separados pueden ejecutar varios bloques. switch permite elegir entre valores concretos. Prueba siempre por debajo, justo en el límite y por encima de una condición.

## 2.4 Sentencias de repetición

Identifica inicio, condición y actualización. while puede ejecutar cero vueltas; do-while al menos una. for reúne las partes del contador. Aprende primero recorridos sencillos, luego acumuladores, centinelas y menús. La validación con try/catch es una ampliación para recuperar entradas incorrectas, no un requisito del primer bucle.
