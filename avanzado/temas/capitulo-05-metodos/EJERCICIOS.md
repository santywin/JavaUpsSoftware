# Ejercicios propuestos — capítulo 5

Resuelve en archivos nuevos con nombres como `Ejercicio01.java`. Para Java, crea el subpaquete `curso.avanzado.capitulo05.practica` y guarda allí tus ejercicios. Así separas tus soluciones de los ejemplos. El capítulo 1 es conceptual. No cambies los ejemplos resueltos. En IntelliJ, crea el subpaquete con **New → Package** y cada clase con **New → Java Class**. Incluye `public static void main(String[] args)` cuando quieras ejecutarla.

Entrega tu código con una explicación corta y las pruebas que hiciste.

## 1. Multiplicar

**Nivel:** Inicial

**Enunciado:** Crea un método que reciba dos enteros y devuelva su producto.

**Comprobación:** Para 4 y -3: -12; para 0 y 9: 0.

## 2. Temperatura

**Nivel:** Práctica

**Enunciado:** Convierte Celsius a Fahrenheit en un método double.

**Comprobación:** 0: 32; 100: 212; -40: -40.

## 3. Mayor

**Nivel:** Práctica

**Enunciado:** Devuelve el mayor de dos enteros desde un método.

**Comprobación:** Para 5 y 5: 5; para -3 y -8: -3.

## 4. Contar pares

**Nivel:** Reto del capítulo

**Enunciado:** Recibe un límite entero no negativo y devuelve cuántos pares hay de 1 hasta ese límite.

**Comprobación:** Con 0: 0; con 7: 3.
