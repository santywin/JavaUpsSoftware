# 5. Métodos

Cuando una tarea se repite, podemos darle un nombre y escribirla en un método. Así la usamos desde distintos lugares sin copiar las mismas instrucciones. Empezaremos con saludos y cálculos pequeños.

El parámetro se declara en el método; el argumento se envía en la llamada. `return` devuelve un valor y termina esa llamada. `void` indica que no se devuelve un valor. Los métodos `static` de estos ejemplos se llaman desde main sin crear un objeto propio. La sobrecarga usa el mismo nombre con diferentes parámetros.
