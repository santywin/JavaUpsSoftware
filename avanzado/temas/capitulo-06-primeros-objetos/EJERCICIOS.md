# Ejercicios propuestos — capítulo 6

Resuelve en archivos nuevos con nombres como `Ejercicio01.java`. Para Java, crea el subpaquete `curso.avanzado.capitulo06.practica` y guarda allí tus ejercicios. Así separas tus soluciones de los ejemplos. El capítulo 1 es conceptual. No cambies los ejemplos resueltos. En IntelliJ, crea el subpaquete con **New → Package** y cada clase con **New → Java Class**. Incluye `public static void main(String[] args)` cuando quieras ejecutarla.

Entrega tu código con una explicación corta y las pruebas que hiciste.

## 1. Libro

**Nivel:** Inicial

**Enunciado:** Crea una clase con título y autor privados, constructor y método mostrar.

**Comprobación:** Dos objetos con títulos distintos deben mostrar sus propios datos.

## 2. Estudiante

**Nivel:** Práctica

**Enunciado:** Crea nombre y nota privados, constructor y método aprueba con umbral 7; usa notas válidas.

**Comprobación:** Nota 6: false; nota 7: true.

## 3. Actualizar nombre

**Nivel:** Reto del capítulo

**Enunciado:** Añade un método para cambiar nombre y otro para obtenerlo.

**Comprobación:** Cambiar el primer objeto no debe cambiar el segundo.
