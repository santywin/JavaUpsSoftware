# 6. Primeras clases y objetos

Un nombre y una nota pueden pertenecer al mismo estudiante. Una clase nos permite reunir esos datos y las operaciones que trabajan con ellos. Crearemos dos estudiantes para ver qué conserva cada objeto.

Una clase describe una estructura; cada objeto es una instancia. Un atributo pertenece al estado del objeto. Un constructor inicializa la instancia y no tiene tipo de retorno. `this` se refiere al objeto actual. `private` limita el acceso directo. Los métodos de instancia trabajan con los atributos del objeto receptor.
