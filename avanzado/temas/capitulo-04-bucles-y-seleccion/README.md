# 4. Bucles y selección de opciones

Si queremos mostrar los números del 1 al 100, no necesitamos escribir cien instrucciones. Un bucle repite un bloque mientras se cumpla una condición. Lo importante es entender qué cambia en cada vuelta y cuándo termina.

Empieza con inicio, condición y actualización. `while` puede ejecutar cero vueltas; `do-while` al menos una. `for` reúne inicio, condición y actualización. Un contador cuenta vueltas; un acumulador reúne resultados. El centinela señala el final y no se procesa como dato. `break` termina el bucle o switch más cercano; `continue` omite el resto de la vuelta del bucle.
