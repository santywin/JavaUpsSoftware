# Ejercicios propuestos — capítulo 8

Resuelve en archivos nuevos con nombres como `Ejercicio01.java`. Para Java, crea el subpaquete `curso.avanzado.capitulo08.practica` y guarda allí tus ejercicios. Así separas tus soluciones de los ejemplos. El capítulo 1 es conceptual. No cambies los ejemplos resueltos. En IntelliJ, crea el subpaquete con **New → Package** y cada clase con **New → Java Class**. Incluye `public static void main(String[] args)` cuando quieras ejecutarla.

Entrega tu código con una explicación corta y las pruebas que hiciste.

## 1. Composición

**Nivel:** Inicial

**Enunciado:** Crea un Curso que contenga un Aula.

**Comprobación:** Dos cursos pueden mostrar códigos de aula diferentes.

## 2. Contador compartido

**Nivel:** Práctica

**Enunciado:** Cuenta objetos con un atributo static incrementado en el constructor.

**Comprobación:** Crear tres objetos nuevos en una ejecución debe dar 3.

## 3. Constructores

**Nivel:** Reto del capítulo

**Enunciado:** Ofrece un constructor con nombre y otro sin argumentos que use Sin nombre.

**Comprobación:** Ambas formas de construcción deben producir objetos utilizables.
