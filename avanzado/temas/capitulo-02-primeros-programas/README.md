# 2. Primeros programas

Vamos a empezar mostrando un mensaje. Después guardaremos datos en variables, haremos algunas cuentas y leeremos lo que se escribe en el teclado. No hace falta entender todas las palabras del primer archivo para ejecutarlo.

Una variable tiene nombre, tipo y valor. `=` asigna. Un texto entre comillas es un literal. En `"Total: " + (a + b)`, los paréntesis hacen la suma antes de concatenar. La división entre enteros descarta la parte fraccionaria hacia cero.
