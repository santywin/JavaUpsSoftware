# Ejercicios propuestos — capítulo 2

Resuelve en archivos nuevos con nombres como `Ejercicio01.java`. Para Java, crea el subpaquete `curso.avanzado.capitulo02.practica` y guarda allí tus ejercicios. Así separas tus soluciones de los ejemplos. El capítulo 1 es conceptual. No cambies los ejemplos resueltos. En IntelliJ, crea el subpaquete con **New → Package** y cada clase con **New → Java Class**. Incluye `public static void main(String[] args)` cuando quieras ejecutarla.

Empieza por el ejercicio de nivel Inicial. Resuelve los siguientes cuando el primero te salga con claridad. Antes de programar escribe los pasos con tus palabras. Entrega tu código con una explicación corta y las pruebas que hiciste.

## 1. Presentación

**Nivel:** Inicial

**Enunciado:** Muestra nombre, curso y meta en tres líneas.

**Comprobación:** La salida debe ocupar tres líneas.

## 2. Producto

**Nivel:** Práctica

**Enunciado:** Declara precio 2.50 y cantidad 3; calcula el total.

**Comprobación:** Resultado numérico: 7.5.

## 3. Rectángulo

**Nivel:** Práctica

**Enunciado:** Pide base y altura enteras positivas y muestra área y perímetro; por ahora asume entrada válida.

**Comprobación:** Con 4 y 3: área 12, perímetro 14.

## 4. Segundos

**Nivel:** Reto del capítulo

**Enunciado:** Convierte una cantidad entera no negativa de minutos en segundos. Supón un dato válido y pequeño para que el resultado quepa en int.

**Comprobación:** Con 0: 0; con 3: 180.

En este capítulo se suponen entradas del tipo y rango pedidos. Todavía no tienes que rechazarlas con if ni gestionar letras. Usa [la ayuda para crear tu primera clase](../../MI-PRIMER-EJERCICIO.md).
