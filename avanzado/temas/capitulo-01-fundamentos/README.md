# 1. Fundamentos y entorno

Antes de abrir Java, pensemos en una tarea sencilla: recibir dos números, sumarlos y mostrar el resultado. Esos pasos ya forman un algoritmo. En este tema veremos cómo llevar una idea así a un programa.

Un algoritmo describe pasos. El código expresa esos pasos en un lenguaje. Compilar y ejecutar son acciones diferentes: corregir el archivo fuente no cambia una compilación anterior hasta volver a compilar.
