# Antes del primer programa

Un programa contiene instrucciones. El hardware es la parte física; el software son los programas. La memoria mantiene datos en uso y el almacenamiento conserva archivos. Un algoritmo describe pasos ordenados para resolver una tarea.

Ejemplo cotidiano: recibir dos cantidades, sumarlas y mostrar el resultado. En pseudocódigo:

```text
Leer primera cantidad
Leer segunda cantidad
Calcular suma
Mostrar suma
```

Una clase puede describir un tipo de objeto. Por ejemplo, una bicicleta tiene datos (color) y comportamientos (frenar). Todavía no necesitamos programarla.

## Preparación del entorno

Instala un JDK 21 o posterior. Comprueba `java -version` y `javac -version` en la terminal. Un IDE ayuda a escribir código, pero necesita un JDK configurado.

Recorrido de ejecución: archivo `.java` → compilador `javac` → archivo `.class` con bytecode → máquina virtual de Java. En el capítulo 2 haremos este recorrido con un mensaje.
