# 3. Condiciones: if y else

Hasta ahora las instrucciones se ejecutaban una detrás de otra. Con `if` podemos decidir qué hacer según un dato: mostrar si un número es par, comparar notas o aplicar un descuento.

Una comparación produce un booleano. En una cadena `if / else if / else` solo se toma un camino. Varios `if` independientes pueden ejecutar varios bloques. `&&` exige ambas condiciones; `||` exige al menos una; `!` niega. No escribas `;` inmediatamente después de `if (...)`.
