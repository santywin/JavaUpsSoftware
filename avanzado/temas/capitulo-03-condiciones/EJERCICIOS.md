# Ejercicios propuestos — capítulo 3

Resuelve en archivos nuevos con nombres como `Ejercicio01.java`. Para Java, crea el subpaquete `curso.avanzado.capitulo03.practica` y guarda allí tus ejercicios. Así separas tus soluciones de los ejemplos. El capítulo 1 es conceptual. No cambies los ejemplos resueltos. En IntelliJ, crea el subpaquete con **New → Package** y cada clase con **New → Java Class**. Incluye `public static void main(String[] args)` cuando quieras ejecutarla.

Empieza por el ejercicio de nivel Inicial. Resuelve los siguientes cuando el primero te salga con claridad. Antes de programar escribe los pasos con tus palabras. Entrega tu código con una explicación corta y las pruebas que hiciste.

## 1. Signo

**Nivel:** Inicial

**Enunciado:** Pide un entero y clasifícalo como positivo, negativo o cero.

**Comprobación:** Prueba -4, 0 y 9; cada uno debe mostrar una sola categoría.

## 2. Paridad

**Nivel:** Práctica

**Enunciado:** Pide un entero e indica si es par o impar.

**Comprobación:** 0 y -4 son pares; 7 es impar.

## 3. Mayor

**Nivel:** Práctica

**Enunciado:** Pide tres enteros y muestra el mayor, admitiendo empates.

**Comprobación:** Para -5, -2 y -8: -2; para 6, 6 y 1: 6.

## 4. Nota

**Nivel:** Práctica

**Enunciado:** Valida nota entera de 0 a 10; aprueba desde 7, refuerzo por debajo.

**Comprobación:** -1 y 11: inválida; 6: refuerzo; 7: aprobado.

## 5. Descuento

**Nivel:** Reto del capítulo

**Enunciado:** Aplica 10% si la compra no negativa alcanza 100. Rechaza valores negativos.

**Comprobación:** 99: sin descuento; 100: total 90; -1: inválida.
