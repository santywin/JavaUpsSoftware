# Ejercicios propuestos — capítulo 7

Resuelve en archivos nuevos con nombres como `Ejercicio01.java`. Para Java, crea el subpaquete `curso.avanzado.capitulo07.practica` y guarda allí tus ejercicios. Así separas tus soluciones de los ejemplos. El capítulo 1 es conceptual. No cambies los ejemplos resueltos. En IntelliJ, crea el subpaquete con **New → Package** y cada clase con **New → Java Class**. Incluye `public static void main(String[] args)` cuando quieras ejecutarla.

Entrega tu código con una explicación corta y las pruebas que hiciste.

## 1. Promedio

**Nivel:** Inicial

**Enunciado:** Calcula el promedio de {8, 6, 10} conservando decimales.

**Comprobación:** Promedio 8.0.

## 2. Máximo

**Nivel:** Práctica

**Enunciado:** Encuentra el mayor de un arreglo no vacío, sin ordenar.

**Comprobación:** {-8, -3, -12}: -3.

## 3. Buscar

**Nivel:** Práctica

**Enunciado:** Indica si un entero aparece en un arreglo.

**Comprobación:** En {2, 4, 6}, buscar 4: true; buscar 5: false.

## 4. Lista

**Nivel:** Práctica

**Enunciado:** Crea una lista de materias y evita agregar duplicados exactos con contains.

**Comprobación:** Agregar Java dos veces debe conservar un solo Java.

## 5. Matriz

**Nivel:** Reto del capítulo

**Enunciado:** Calcula la suma de cada fila de {{8, 6}, {10, 7}}.

**Comprobación:** Resultados 14 y 17.
