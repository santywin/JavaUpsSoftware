# 7. Arreglos y listas

Guardar una nota en una variable es sencillo. Para trabajar con varias notas usaremos arreglos y listas. Vamos a recorrerlos, buscar valores y calcular resultados sin crear una variable por cada dato.

En un arreglo de longitud n, los índices válidos van de 0 a n-1. `length` es un campo del arreglo; `size()` es un método de la lista. Un ArrayList puede crecer. `get(0)` y `valores[0]` requieren al menos un elemento. Las matrices de Java son arreglos de arreglos y sus filas pueden tener distintas longitudes.
