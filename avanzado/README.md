Los capítulos 1 a 7 permiten repetir mensajes, variables, condiciones, bucles, métodos, objetos, arreglos y listas. Desde el capítulo 8 se profundiza en composición, herencia, polimorfismo, interfaces y excepciones.

Los ejemplos ejecutables están en `src/main/java/curso/avanzado`, dentro del proyecto principal. Los paquetes llevan el prefijo `curso.avanzado`; por eso pueden convivir con los ejemplos de las unidades sin repetir clases. Usa el mismo pom.xml y el mismo proyecto de IntelliJ.

Cada capítulo conserva sus ejercicios y explicaciones. No hace falta estudiar esta sección para completar las primeras unidades.
